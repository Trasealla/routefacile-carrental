# RouteFacile - Car Rental System

A modern car rental web application built with React, TypeScript, and Vite.

## Features

- 🏠 **Home page** with hero search and featured vehicles
- 🚗 **Car listing** with advanced filters (location, category, transmission, fuel, price)
- 📋 **Car detail page** with full specs and integrated booking form
- ✅ **Booking confirmation** page with booking summary
- 📱 Fully responsive design

## Tech Stack

- **React 19** + **TypeScript**
- **React Router v7** for client-side routing
- **Vite** for fast development & builds
- Pure CSS (no external UI library)

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Build

```bash
npm run build
```
